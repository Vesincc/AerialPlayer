# AerialPlayer

macOS 菜单栏工具，自动读取当前苹果航拍壁纸，在桌面底层循环播放原始视频，每轮用 1 秒交叉淡化衔接。

## 使用

1. 在系统设置中选中并下载一张航拍壁纸，将其应用到所有空间。
2. 在 Xcode 中打开 `AerialPlayer.xcodeproj`，选择 `AerialPlayer` 并运行。
3. 在菜单栏中暂停、继续、重新读取当前壁纸或退出。
   “播放速度”滑杆可在 0.25×～2× 之间即时调节，旁边显示当前倍速，点击“1×”恢复正常速度；“静音”可开关声音。选择会保存，下次启动继续使用，默认 1×、静音。素材没有音轨时，取消静音也不会有声音。
   “填充模式”提供 `aspectFit`（完整显示，留黑边）、`aspectFill`（等比铺满，裁切）和 `resize`（拉伸铺满），默认 `aspectFill`。切换使用 0.35 秒平滑动画，保存选择并应用于所有屏幕；暂停视频时仍可调整填充模式。
4. 勾选“开机自动启动”，下次登录 macOS 时自动运行。若显示“待系统允许”，点击下方设置入口完成允许；再次点击开关可取消注册。

自动启动使用 `SMAppService.mainApp`，菜单每次打开时读取系统实际状态。建议从固定位置（例如 `/Applications`）运行并注册，避免调试构建清理后登录项指向失效路径。

程序只读系统壁纸配置和视频文件，不下载、不转换、不替换苹果文件。退出时关闭自己的桌面窗口，原来的系统壁纸继续显示。

## 实现

- `CurrentWallpaperResolver`：在后台读取 `Store/Index.plist`，解析当前航拍的 `assetID`，对应 `aerials/videos/<assetID>.mov`，读取名称索引。
- `AerialPlayerApp`：菜单栏程序入口，启动和关闭控制器。
- `WallpaperController`：协调每个屏幕的壁纸选择、播放设置和菜单状态。
- `WallpaperSession`：持有一组视频播放器和桌面窗口，负责加载、首帧展示、壁纸切换淡化以及旧会话释放。
- `StillWallpaperStore`：按屏幕管理图片解码任务和占位窗口；视频会话接管窗口时转移所有权，避免重新显示图片引起闪动。
- `WallpaperEventMonitor`：持有系统通知和目录观察者，统一管理刷新防抖和系统暂停条件。
- `CrossfadeVideoPlayer`：两个 `AVPlayer` 交替播放，正常情况下只有当前播放器持有 `AVPlayerItem`。结尾前 3 秒才创建并预热备用项，交叉淡化结束后解除旧图层的播放器绑定、释放旧播放项与观察者，不长期保留第二份解码和缓冲资源。
- `DesktopWallpaperWindow`：桌面图标下方、不接受鼠标事件的窗口，使用 `AVPlayerLayer` 显示视频。
- `StatusBarController`：菜单栏展示及操作入口，控件只创建一次，按状态更新。
- `PlaybackSpeedControl`：速度滑杆、倍速显示和复位按钮，管理滑杆鼠标跟踪。
- `VideoFillMode`：菜单与播放器共享的填充模式。

切换航拍壁纸时保留旧画面，等新视频首帧就绪后用 1 秒交叉淡化替换，再释放旧播放器。连续切换只保留一份旧画面和最新的加载会话；新视频加载失败时恢复旧视频并显示错误。切换到非航拍壁纸时，将播放窗口淡出，露出原生系统壁纸。

从图片壁纸切换到航拍视频时，程序会在图片仍被选中时显示一份按屏幕尺寸缩小的图片，并在切换时复用同一个窗口。新视频首帧就绪后，旧图片在视频上方用 1 秒淡出。图片无法读取时退回窗口淡入；过渡结束后释放图片。

航拍默认按原视频时间轴以 1 倍速播放，可在菜单中调速。调速不改变暂停状态，循环交叉淡化保持 1 秒；淡化期间仅当前播放器输出声音。解码和显示交给 AVFoundation，不转码、不在 Swift 中逐帧绘制。仅在结尾预热下一轮；不将整个视频载入内存。休眠、显示器关闭、锁屏、用户切换以及严重热压力下暂停。

正常播放阶段暂停时释放备用播放项，恢复后按需预热；淡化中暂停则保留两份画面，以保持恢复后的动画连续。重复的系统暂停通知和未变化的窗口尺寸不会重复更新。菜单静态控件保持同一实例；菜单打开时只更新控制状态，关闭后再更新状态文字和显示器条目。滑杆拖动期间不回写其数值，避免干扰原生鼠标跟踪。多屏仍各自播放，以保留独立壁纸与填充模式；未降低原视频画质或帧率。备用项释放后的实际内存回收由 AVFoundation 管理，具体收益需在运行时测量。

## 边界

当前工程以 macOS 27 为目标。识别依赖苹果内部壁纸配置格式，系统升级可能需要调整解析。支持统一壁纸以及 `Displays` 中的独立显示器配置；独立 Space 配置和随机轮播的运行时选择尚未验证，无法确定当前资源时会提示，而不会猜测或播放其他文件。

本地自用版本关闭 App Sandbox，以直接读取用户的壁纸配置和视频目录。未接入系统壁纸私有渲染器，持续播放由本程序的桌面窗口承担。

## 解析验证

`Tests/ResolverChecks.swift` 是独立的 Foundation 命令行检查，不启动 App 或视频播放器。将它与 `CurrentWallpaperResolver.swift` 一起用 `swiftc` 编译，执行时传入测试临时目录；追加 `--live` 可只读验证本机当前统一航拍壁纸。
